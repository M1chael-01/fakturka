# Fakturka

Fakturka is a web application designed for creating and managing invoices.

The project is built using a modern web stack with **React** for the frontend and **Node.js with Express** for the backend.

**Project status: Not done yet**

This project is currently not finished and is being developed as part of a school / learning project.

---

# Features

## Invoice Management

- Create new invoices
- Edit existing invoices
- Store invoices in a database
- Manage invoice items
- Display a list of invoices

## User Interface

- Modern web interface
- Dynamic forms
- Simple invoice management system

## Backend

- REST API for invoice operations
- Communication with database
- Server-side application logic
